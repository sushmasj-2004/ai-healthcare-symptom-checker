# AI HealthCare - Multilingual Symptom Checker

An AI-powered web application that predicts diseases based on symptoms 
in 7 Indian languages.

## Features
- 7 language support (English, Hindi, Kannada, Tamil, Telugu, Marathi, Malayalam)
- Voice input and output
- ML-based disease prediction
- Medical advice and precautions
- Nearby hospital search
- Online doctor consultation
- User login and profile system

## Tech Stack
- Python + Flask
- Scikit-learn
- HTML, CSS, JavaScript
- MyMemory API (Translation)
- Web Speech API (Voice)

## Setup
pip install -r requirements.txt
python app.py
